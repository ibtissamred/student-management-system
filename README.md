# Student Management System

A simple database-driven Student Management System developed using Python and SQLite.

## Project Overview

This project is a desktop-based application that allows users to manage student records through a simple menu-driven interface.

The system stores student information in an SQLite database and provides basic CRUD operations.

## Features

- Add new student records
- View all student records
- Search for a student by ID
- Update student information
- Delete student records
- Store data using SQLite
- Menu-driven command-line interface

## Technologies Used

- Python
- SQLite
- SQL
- VS Code

## Student Information

The system stores:

- Student ID
- Name
- Age
- Major
- Academic Year
- Email
- GPA

## Database

The project uses SQLite to store student information in a local database file called `students.db`.

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```text
python main.py
```

5. Use the menu to manage student records.

## Project Purpose

This project was developed to practice Python programming, database management, SQL, CRUD operations, and connecting a Python application to a relational database.
